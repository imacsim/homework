Запуск сервера:
```
python server.py
```
Запуск клиента:
```
python client.py
```

Поддерживаемые команды:
```/add <text>``` добавить новую задачу

```/list``` показать все задачи

```/done <number>``` отметить задачу как выполненная

```/quit``` завершить работу клиента

Одновременная работа клиентов:
Сервер работает в многопоточном режиме.
На каждое новое подключение запускается отдельный поток.
Это позволяет серверу обрабатывать запросы нескольких клиентов параллельно и независимо друг от друга.

Синхронизация:
Где: в server.py вокруг общего списка задач tasks с помощью threading.Lock() и конструкции with tasks_lock:.
Зачем: для предотвращения состояния гонки и ошибок доступа при одновременном добавлении (/add), чтении (/list) и изменении статуса задач (/done) разными клиентами
