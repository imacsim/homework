# Task Manager
Приложение для создания задач

## Возможности
1. Ввод названия задачи и описания.
2. Выбор приоритета: Low, Medium, Hig.
3. Доп настройки: Important и Send notification.
4. Кнопка Create task добавляет текст задачи в список Python и показывает созданную задачу (также кол-во задач).
5. Кнопка Clear очищает поля и сбрасывает настройки.

Запуск:
```bash
python main.py
```
