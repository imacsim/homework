Курсы криптовалют

Реализованная функциональность

Просмотр списка объектов (/) - отображение всех криптовалют и их статусов.

Просмотр подробной информации (/coins/<id>) - отдельная страница конкретной монеты.

Добавление объекта (/coins/add) - создание новой записи через POST-форму.

Редактирование объекта (/coins/<id>/edit) - изменение существующей записи через GET/POST с предзаполнением полей, 
проверкой данных и перенаправлением на страницу объекта.

Дополнительная функция 1 - Изменение статуса (/coins/<id>/status) - переключение статуса монеты (Обычная / В избранном) 
через POST-запрос.

Дополнительная функция 2 - Удаление объекта (/coins/<id>/delete) - удаление выбранной записи через POST-запрос.
