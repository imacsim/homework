# Что изменено
1. Добавлена обработка отключения сервера в `ReceiveThread`.
2. При потере соединения появляется сообщение в истории, меняется статус и блокируется отправка.
3. Добавлен метод `SendThread.stop()` для остановки отправляющего потока.
4. При закрытии окна организовано завершение обоих потоков и закрытие сокета.

## Обработка потери соединения
`ReceiveThread` обрабатывает сетевые ошибки и случай, когда `recv()` возвращает `None`. 
Информация передается в главное окно через сигнал `disconnected`.
Обработчик показывает причину отключения и отключает поле ввода с кнопкой отправки.

## Остановка SendThread
Метод `stop()` добавляет `None` d `Queue`. Когда `run()` получает это значение, цикл завершается.
При закрытии окна сначала отправляется команда остановки, затем вызывается `socket.shutdown()`, чтобы прервать ожидающие сетевые операции.
После завершения потоков сокет закрывается.
