## Формат сообщения

Каждое сообщение состоит из:

4 байта - длина команды

команда в UTF-8

4 байта - длина данных (payload)

сами данные (payload)

## Поддерживаемые команды

| Команда | Описание                             |
|---------|--------------------------------------|
| JOIN    | Регистрация клиента с именем         |
| TEXT    | Отправка текстового сообщения всем   |
| LIST    | Получить список онлайн-пользователей |
| QUIT    | Корректный выход из чата             |
| ERROR   | Ответ сервера при ошибке             |
